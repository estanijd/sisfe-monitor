🔑 Generar licencias

Abrís la Terminal en tu Mac (⌘ + Espacio → "terminal") y navegás al proyecto:

cd /Users/estanislaodiaz/sisfe_monitor

1 cuenta — u$s 150

# Reemplazá con los datos reales del cliente
python3 license/generator.py "Juan Perez" "juan@gmail.com" --cuentas 1

2 cuentas — u$s 175

python3 license/generator.py "Maria Lopez" "maria@gmail.com" --cuentas 2

3 cuentas — u$s 200

python3 license/generator.py "Carlos Gomez" "carlos@gmail.com" --cuentas 3

Con fecha de vencimiento (si querés)

python3 license/generator.py "Juan Perez" "juan@gmail.com" --cuentas 1 --vence 2027-12-31

Ver todos tus clientes

python3 license/generator.py --lista

Validar un código existente

python3 license/generator.py --validar "SISFE-XXXXXX-..."
⚠️ Guardá siempre una copia de licencias_emitidas.json El archivo está en license/licencias_emitidas.json. Es tu registro de clientes. Está en .gitignore (no se sube a GitHub). Hacé copias de seguridad periódicas.

📦 Distribuir el instalador

Link oficial (siempre apunta a la última versión):

https://github.com/estanijd/sisfe-monitor-releases/releases/latest

Este es el único link que necesitás darle a todos los clientes. Cuando publiques una actualización, el mismo link los lleva a la nueva versión.

🔄 Publicar una actualización

Hacer los cambios en el código (Mac)

Modificar los archivos necesarios. Yo (Claude) te ayudo con esto.

Actualizar el número de versión

Cambiar version.txt y la línea #define MyAppVersion en installer.iss. Ej: 1.0.0 → 1.0.1

Compilar en Windows (cmd como Admin)

git pull origin main → build_windows.bat

Crear el instalador (Inno Setup)

Abrir installer.iss → F9 → queda en Output\SISFE_Monitor_Setup_v1.0.1.exe

Publicar en GitHub Releases

github.com/estanijd/sisfe-monitor-releases → Releases → Draft new release → tag v1.0.1 → adjuntar .exe → Publish.

✅ Los clientes se actualizan solos La próxima vez que abran SISFE Monitor, el programa detecta la nueva versión y les muestra un aviso para descargarla. No necesitás contactar a cada cliente.

🛠️ Soporte a clientes

ProblemaSolución
No recibe emailsRevisar carpeta Spam. Verificar contraseña de app Gmail en el wizard (→ Configurar → paso Email → Enviar email de prueba)
Error de licenciaValidar el código: python3 license/generator.py --validar "SISFE-..."
Login SISFE fallaVerificar que el saldo de 2captcha sea mayor a u$s 0.10. Ingresar a 2captcha.com y recargar.
No corre automáticamenteVerificar que las tareas estén en el Programador de Tareas de Windows. Si no están, abrir SISFE Monitor → Configurar → Finalizar de nuevo.
Quiere agregar una cuentaCobrarle u$s 25 por la cuenta adicional → generar nueva licencia con --cuentas N → enviársela. Abre Configurar → paso Cuentas para agregar las credenciales.

Imprime una tabla con nombre, email, plan, vencimiento y fecha de emisión de cada licencia.
